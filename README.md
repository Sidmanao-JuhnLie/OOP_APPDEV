# OOP_APPDEV
A Mini Projector Reservation System.

Features and Description:
1. User login/Registration - Sign up and log in.
2. Dashboard - Display total projectors and available projector.
3. Reservation list - Browse, search, and sort reservations.
4. reservation status - Track each request’s progress.
5. Equipment Status & Repair logs - Check projector condition and repairs.
6. Projector history timeline - View every past borrower.
7. Approval notifications - Alert users on decisions.
